# Portfolio — Christ AMPHA

Portfolio officiel de **Christ AMPHA** — *Stratège en communication & Créateur de marques*.

## Déploiement en 1 clic sur Netlify

### Méthode 1 : Drag & Drop (Le plus simple et rapide)
1. Rendez-vous sur [app.netlify.com/drop](https://app.netlify.com/drop) (connectez-vous ou créez un compte gratuit).
2. Glissez-déposez directement tout le dossier **`Mobutu`** dans la zone indiquée.
3. Votre site est instantanément en ligne avec une URL sécurisée en `https://...netlify.app` !

### Méthode 2 : Via GitHub / GitLab
1. Poussez le contenu du dossier sur votre dépôt GitHub.
2. Liez votre dépôt sur [Netlify](https://app.netlify.com).
3. Le fichier `netlify.toml` inclus configure automatiquement le publish directory (`.`) et les en-têtes de sécurité/cache.

## Structure des fichiers
- `index.html` : Page principale du portfolio.
- `favicon.svg` : Favicon vectoriel officiel (monogramme CA).
- `netlify.toml` : Configuration Netlify (en-têtes HTTP de sécurité et mise en cache des médias).
- `_redirects` : Règles de redirection propre SPA / Single Page.
- `profil.jpeg` : Votre photo de profil officielle.
- Les planches et maquettes sources (`Artboard *.png`, `Plan de travail *`).
